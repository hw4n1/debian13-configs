# i3

Atajos de gestion de ventanas de `config/i3/config`. La tecla `$mod` es **Super** (Mod4) y el teclado esta en `latam`, por eso la cuarta tecla de direccion es `ñ` y no `;`.

Regla mental: i3 no coloca ventanas, las **divide**. Cada ventana nueva parte en dos el espacio de la que tenga el foco, en la direccion que marque el ultimo `split`. Si algo aparece donde no querias, no muevas la ventana: cambia el split antes de abrirla.

## Lo minimo para sobrevivir

| Atajo | Que hace |
|-------|----------|
| `Super+Return` | Terminal nueva |
| `Super+d` | Lanzador de aplicaciones (rofi) |
| `Super+Shift+q` | Cerrar la ventana con foco |
| `Super+f` | Pantalla completa |
| `Super+j` `k` `l` `ñ` | Mover el foco izquierda, abajo, arriba, derecha |
| `Super+1`..`0` | Ir al escritorio 1 a 10 |
| `Super+Shift+r` | Reiniciar i3 conservando la sesion |
| `Super+F1` | Abrir esta chuleta |

## Foco

Las flechas hacen lo mismo que las letras, por si aun no tienes la posicion en los dedos.

| Atajo | Que hace |
|-------|----------|
| `Super+j` / `Super+Left` | Foco a la izquierda |
| `Super+k` / `Super+Down` | Foco abajo |
| `Super+l` / `Super+Up` | Foco arriba |
| `Super+ñ` / `Super+Right` | Foco a la derecha |
| `Super+a` | Foco al contenedor padre (selecciona el grupo, no la ventana) |
| `Super+space` | Saltar entre la capa flotante y la capa en mosaico |

`Super+a` es la tecla que desbloquea el resto: sube un nivel en el arbol, asi que lo que hagas despues (mover, cambiar layout, pantalla completa) se aplica al bloque entero y no a una sola ventana. Pulsala varias veces para subir mas.

## Mover ventanas

| Atajo | Que hace |
|-------|----------|
| `Super+Shift+j` / `Left` | Mover la ventana a la izquierda |
| `Super+Shift+k` / `Down` | Mover la ventana abajo |
| `Super+Shift+l` / `Up` | Mover la ventana arriba |
| `Super+Shift+ñ` / `Right` | Mover la ventana a la derecha |
| `Super+Shift+1`..`0` | Enviar la ventana al escritorio 1 a 10 |
| `Super` + arrastrar con el raton | Mover una ventana flotante desde cualquier punto |
| Arrastrar la barra de titulo | Reordenar una ventana en mosaico |

Al mover contra el borde de la pantalla, la ventana salta al monitor contiguo.

## Dividir y organizar

| Atajo | Que hace |
|-------|----------|
| `Super+h` | La proxima ventana se abre **al lado** (division horizontal) |
| `Super+v` | La proxima ventana se abre **debajo** (division vertical) |
| `Super+e` | Alternar entre division horizontal y vertical del contenedor |
| `Super+s` | Layout apilado (titulos en lista vertical) |
| `Super+w` | Layout en pestañas |

`split` afecta a la ventana **siguiente**, no a la actual: se pulsa antes de abrir. Los layouts apilado y pestañas se combinan con `Super+a`: agrupa un bloque, lo pasas a pestañas y ganas espacio sin cerrar nada.

## Flotante y tamaño

| Atajo | Que hace |
|-------|----------|
| `Super+Shift+space` | Alternar entre flotante y mosaico |
| `Super+f` | Pantalla completa |
| `Super+r` | Entrar en modo *resize* |
| `Super` + boton derecho arrastrando | Redimensionar una flotante con el raton |

Dentro del modo *resize* (la barra avisa de que estas en el):

| Tecla | Que hace |
|-------|----------|
| `j` / `Left` | Estrechar |
| `ñ` / `Right` | Ensanchar |
| `k` / `Down` | Alargar hacia abajo |
| `l` / `Up` | Acortar |
| `Return`, `Escape` o `Super+r` | Volver al modo normal |

## Scratchpad

El scratchpad es un escritorio invisible: la ventana sigue viva, pero fuera de pantalla.

| Atajo | Que hace |
|-------|----------|
| `Super+Shift+Return` | Terminal kitty que nace ya en el scratchpad (1100x650) |
| `Super+minus` | Mostrar u ocultar la ventana del scratchpad |

No hay atajo para enviar una ventana cualquiera al scratchpad. Si lo quieres, añade a `config/i3/config`:

```
bindsym $mod+Shift+minus move scratchpad
```

## Escritorios

| Atajo | Que hace |
|-------|----------|
| `Super+1`..`Super+0` | Ir al escritorio (el `0` es el 10) |
| `Super+Shift+1`..`0` | Enviar la ventana con foco a ese escritorio |

Los escritorios se crean al usarlos y desaparecen al quedarse vacios.

## Sesion

| Atajo | Que hace |
|-------|----------|
| `Super+Shift+c` | Recargar la configuracion (aplica cambios del config) |
| `Super+Shift+r` | Reiniciar i3 en el sitio, conservando ventanas y layout |
| `Super+Shift+e` | Salir de i3 y cerrar la sesion X (pide confirmacion) |
| `Super+Shift+x` | Bloquear la pantalla (i3lock) |

Tras editar `config/i3/config`, `Super+Shift+c`. Si el cambio toca `exec_always` (polybar, picom, fondo), hace falta `Super+Shift+r`.

## Fuera de las ventanas

| Atajo | Que hace |
|-------|----------|
| `Super+d` | Lanzador de aplicaciones (rofi drun) |
| `Super+F1` | Esta chuleta en rofi; Enter abre el documento completo |
| `Super+c` | Historial del portapapeles (greenclip) |
| `Print` | Captura de toda la pantalla al portapapeles |
| `Super+Print` | Captura de una region seleccionada |
| `XF86AudioRaise/Lower/Mute` | Volumen |
| `XF86MonBrightnessUp/Down` | Brillo |

## i3-msg (scripting)

Todo atajo es una orden de i3 y se puede lanzar desde la terminal o un script:

```bash
# El arbol completo de contenedores en JSON (para entender por que algo esta donde esta)
i3-msg -t get_tree | jq '.'

# Escritorios y cual esta activo
i3-msg -t get_workspaces | jq '.[] | {num, focused, output}'

# Ejecutar cualquier comando de i3
i3-msg 'workspace number 3'
i3-msg '[class="Firefox"] focus'
i3-msg '[title="scratchpad"] scratchpad show'

# Abrir un layout guardado en el escritorio actual
i3-msg 'append_layout ~/.config/i3/layout-recon.json'

# Escuchar eventos (util para depurar reglas for_window)
i3-msg -t subscribe -m '["window"]'

# La clase y el titulo de una ventana, para escribir reglas for_window
xprop | grep -E 'WM_CLASS|WM_NAME'
```

## Notas de esta configuracion

* `Super+d` es rofi, asi que el `focus child` por defecto de i3 esta comentado. Para bajar en el arbol, usa el raton o `i3-msg 'focus child'`.
* El teclado se fija a `latam` en el arranque. Con otra distribucion, `ntilde` en el config deja de existir: cambialo por `semicolon` en `config/i3/config`.
* Las reglas automaticas de ventana (`for_window`) viven en el mismo config. La del scratchpad es el ejemplo a copiar.
